# MOB-014：会话手机工具

状态：待实施

负责人：`mob_014_mobile_conversation_tools`

工作分支：`dev`

目标版本：`0.2.1`

范围：Mira Mobile；优先使用 React Native / Android / iOS 现有系统能力

Desktop / Host 依赖：无新增依赖

## 背景

聊天页已经展示“分享”和“在聊天中查找”入口，但当前均不可用。两项能力都可以在手机本地完成，不需要等待 Mira Host 新合同，适合在 0.2.1 激活为真实能力。

## 目标

把现有聊天页中的“分享”和“在聊天中查找”接成可用的手机端工具，不扩展成新的内容管理系统。

## 1. 系统分享

- 复用 React Native / Android / iOS 原生 Share Sheet；
- 顶部分享按钮与会话菜单“分享”必须调用同一实现；
- 分享内容以当前会话可安全读取的文本为基础；
- 不分享 Device Credential、Host URL、内部 run/tool 元数据或隐藏系统消息；
- 用户取消系统分享不算错误；
- 分享失败显示轻量真实错误，不伪造成功。

## 2. 当前聊天内查找

- 搜索范围只限当前已读取到 Mobile 的当前 Thread 消息；
- 支持输入关键词、匹配数量、上一个 / 下一个匹配；
- 定位到对应消息，不调用全局 `/threads` 搜索冒充全文索引；
- 默认只搜索用户可见文本，不把 tool/system 隐藏内容暴露为搜索结果；
- 关闭查找后不修改 Host Thread、已读状态或消息内容；
- 大量消息时避免每次键入造成明显主线程卡顿。

## 并行边界

MOB-014 只拥有“会话工具入口与本地工具状态”。若需要修改 `ChatScreen.tsx`：

- MOB-012 未合入时不得并发改 Agent 状态机区域；
- 优先抽独立 Share helper / Find-in-chat 组件；
- MOB-013 同期施工时不得同时重写 Message renderer。

MOB-015 可独立并行。

## 测试要求

- 顶部分享与菜单分享同源；
- 分享数据不包含凭证、Host URL、隐藏 system/tool 内容；
- 取消 Share Sheet 不报错；
- 查找支持 0 / 1 / 多条匹配；
- 上一个 / 下一个循环或边界行为明确且稳定；
- 中文、英文、大小写基础匹配可用；
- 关闭查找后聊天发送 / streaming / scroll 行为不退化。

## 验收

1. 用户能从聊天页调起 Android / iOS 系统分享；
2. 用户能在当前聊天内输入关键词并定位匹配消息；
3. 两项能力离线也能对已加载内容工作；
4. 不泄漏认证与内部运行数据；
5. 不新增 Host 依赖。

## 非目标

- 不做跨会话全文搜索；
- 不做图片 OCR 搜索；
- 不做导出 PDF / Markdown 文件；
- 不做分享链接服务；
- 不做“添加到首页 / 归档 / 添加到项目”。
