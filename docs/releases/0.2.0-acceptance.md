## 晋级规则

严格按照仓库约定执行：

1. 发版准备先合入 `dev`；
2. `dev -> test` 通过晋级 PR；
3. `test -> prod` 通过晋级 PR；
4. `prod` 不直接推送；
5. 正式 tag 必须指向最终 `prod` 发布提交，并由生产发布流水线校验。
